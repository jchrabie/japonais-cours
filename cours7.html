Cours 7 — Les mots de position et la particule に

Préciser où se trouve une chose ou une personne, indiquer un moment et exprimer une destination.

1. Les sept mots de position

Le support mentionne aussi 向こう (むこう, mukou) : de l'autre côté, et 間 (あいだ, aida) : entre. Ils sont présentés dans l'activité orale.

2. Décrire une position : の + mot de position

Structure : [Sujet] は [Repère] の [Position] に あります / います.

の relie le repère au mot de position : えきの みぎ = à droite de la gare ; つくえの うえ = sur le bureau. L'ordre est celui du japonais : repère, puis position.

  • コンビニは えきの みぎに あります。 — Le konbini est à droite de la gare.
  • ほんは つくえの うえに あります。 — Le livre est sur le bureau.
  • ねこは いすの したに います。 — Le chat est sous la chaise.
  • こどもは へやの なかに います。 — L'enfant est dans la chambre.

Rappel : ある / あります pour les choses ; いる / います pour les êtres vivants.

3. Demander où se trouve quelque chose

[Sujet] は どこに ありますか / いますか。 = Où est… ?

コンビニは どこに ありますか。 — Où est le konbini ?
さすけは どこに いますか。 — Où est Sasuke ?
えきの まえに あります。 — C'est devant la gare.

4. に : les trois emplois

A. Un moment précis

[Heure / jour précis] + に + verbe. はちじに おきます。 — Je me lève à 8 h. かようびに いきます。 — J'y vais mardi.

Attention : に ne s'ajoute pas à いま (maintenant), きょう (aujourd'hui) et まいにち (tous les jours) : まいにち べんきょうします。

B. Le lieu où l'on se trouve

[Sujet] は [Lieu] に います / あります. なるとは がっこうに います。 — Naruto est à l'école.

C. La destination d'un déplacement

[Sujet] は [Destination] に + verbe de déplacement.

なるとは とうきょうに いく。 — Naruto va à Tokyo.
さくらは がっこうに いきます。 — Sakura va à l'école.
カカシは むらに かえります。 — Kakashi rentre au village.

5. Ne pas confondre に et で / を

Le cours annonce que で sera étudié plus en détail au prochain cours : がっこうで べんきょうします。 — J'étudie à l'école.

Pour le verbe 出る（でる, deru : sortir / quitter un lieu), le corrigé du support utilise を : うちを でます。 — Je sors de la maison. Ce n'est pas に.

À retenir

  • の relie le lieu repère au mot de position.
  • ある / いる décrivent la présence des choses / êtres vivants.
  • に marque un moment précis, un lieu où l'on se trouve ou une destination.
  • いま・きょう・まいにち ne prennent pas に dans les exemples du cours.
  • で sert au lieu où se déroule une action ; を marque le lieu quitté avec 出る dans l'exemple du corrigé.
